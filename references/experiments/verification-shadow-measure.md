# 검증 효율 shadow 측정과 판정

이 문서는 승인된 신규 1.0.2 A/B 실험의 집계 때만 읽는다. 자동 통계 엔진을 추가하지 않고, 메인이 기존 파일과 계산 명령으로 재현 가능한 `shadow-summary.md`를 만든다. `_workspace\measure.md`에는 그 경로만 연결해도 된다.

## 원자료와 독립 단위

메인은 `shadow-plan.json`과 hash, 원 task·판정·로그·고정 사본·상태 파일·관측 파일·원 측정표의 경로와 hash를 먼저 적는다. 값이 없으면 `미관측`이며 0으로 채우지 않는다.

독립 단위는 `run 경로 + round`다. 같은 run/round의 여러 task와 재시도는 한 독립 표본으로 중복 제거하고, task별 결과는 그 단위의 하위 근거로 남긴다. A/B, 작업 유형, 층별 모집단 수와 제외 사유를 각각 적는다.

## 표본 고정

결과를 보기 전에 계획의 `strata`, `seed`, `ratio`, `rotation`으로 원 모집단에서 표본 목록을 고정한다. `shadow-summary.md`에 아래를 남긴다.

- 원 모집단 파일·hash와 run/round 중복 제거 전후 목록
- 층 정의·층별 수·제외 목록과 이유
- seed·비율·회전 규칙·정렬 규칙
- 그대로 다시 실행할 추출 명령, 입력 파일·hash, 출력 표본 목록·hash

계획값이나 계산 명령이 없으면 표본을 만들지 않는다. 결과 뒤 seed·층·비율·회전을 바꾼 회차는 탐색 자료이며 N에 세지 않는다.

## 비용과 시간

사례마다 원 task 측정표 경로·hash와 단위를 붙이고 세 묶음으로 나눈다.

| 묶음 | 포함할 값 |
| --- | --- |
| 현행 운영 | 기존 전면 검토 또는 전체 CI 시간·자원 점유·대기 |
| 후보 운영 | 근거 수집·hash 대조·분류·무효화·정상 표본 재독 |
| 실험 추가 | baseline/current/final 추가 instance, 전면 대조, 실험 문서·기록·집계 |

관측 가능한 agent 사용량, 검토·검사 wall time, 자원 점유·대기, 증거 작성 시간을 원자료 위치와 함께 쓴다. 잠재 절감은 `현행 운영 - 후보 운영`, 실험 전체 지출은 세 묶음을 합쳐 별도로 보인다. 실제 실행을 생략하지 않았으므로 잠재 절감을 실제 절약이라 하지 않는다.

## 계산 기록

`shadow-summary.md`에 계획의 S/H/E/N/counts_by_type와 A의 R/Q/`calculation`을 그대로 옮기고 plan 경로·hash를 단다. 항목마다 계산 명령, 입력 파일·hash, 출력 원문·결과, 결측·제외 수를 기록한다.

- N과 유형별 수는 독립 run/round 단위로 센다.
- E는 독립 결론이 입증된 적용 가능 사례 / 계획 모집단이다. 기계 `frozen/observed/indeterminate`만으로 분자에 넣지 않는다.
- S는 계획 단위의 잠재 순절감, H는 후보 운영 관리비다. 실험 추가비용도 별도로 제시한다.
- A는 독립 final read-judge가 `proven`으로 판정한 사례만 품질 비교에 넣고, 계획 계산법으로 숨은 예외율 단측 신뢰상한을 구해 R/Q와 대조한다.
- B는 기계 `indeterminate`에 별도 저장된 독립 reviewer 결론별 수와 `possible` 뒤 새 CI 불일치 수를 낸다. 자동 기계 상태나 `impossible`에 결론을 추정해 보태지 않는다.

## 최종 판정 경계

메인은 원자료를 모으고 계산을 실행해 결과를 기록할 뿐 `입증`, 승격 또는 정책 완화를 선언하지 않는다. 별도 final read-judge가 원자료·각 hash·중복 제거·표본 명령·계산식·출력을 직접 대조해 `입증/미입증/판정불가`와 실패 위치를 쓴다.

필수 계획값, N, 유형별 수, 원자료, 계산 명령·입력·결과 가운데 하나라도 없거나 종료일이 지났으면 현행 유지로 닫는다. S/H/E/R/Q 기준 미달, 차단·중요 거짓음성, B `possible` 뒤 불일치도 현행 유지와 실험 중단 사유다. 원인을 고쳐 자동 재개하거나 새 수치 기본값을 만들지 않는다.
