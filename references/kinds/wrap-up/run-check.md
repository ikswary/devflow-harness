# 마무리 task: 실행 판정

읽는 때: 실행 판정자가 마무리 task(`wrap-up`)의 내보낼 commit을 최종 배포 후보로 검증할 때.

- 문서 변경까지 커밋한 흐름·통합 폴더의 깨끗한 HEAD에서 전체 검증을 새로 실행한다. 앞 task의 부분 검사나 앞 후보 기록을 재사용하지 않는다.
- `judge-run.md`의 공통 두 절과 `## 최종 배포 후보 CI`를 쓴다. `검증 commit`은 검사한 HEAD, `검증 artifact`는 CI 실행·산출물 식별자다.
- 메인이 내보내기를 실행한 뒤 완료 전이에서 `exported_commit`과 검증 commit을 대조한다. 둘은 유효한 7~40자 16진수 Git SHA여야 한다.
