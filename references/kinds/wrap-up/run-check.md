# 마무리 task: 실행 판정

읽는 때: 실행 판정자가 마무리 task(`wrap-up`)의 내보낼 commit을 최종 배포 후보로 검증할 때.

- 메인이 문서 변경까지 커밋한 흐름·통합 폴더의 깨끗한 HEAD에서, 실행 승인 전에 전체 검증을 새로 실행한다.
- `judge-run.md`의 공통 두 절과 `## 최종 배포 후보 CI`를 쓴다. `검증 commit`은 검사한 HEAD, `검증 artifact`는 CI 실행·산출물 식별자다.
- 실패하면 그 시험만 프롬프트가 준 문서 커밋 전 끝에서 다시 돌려 `## 최종 CI 실패 원인`에 `- 원인: 문서`(그 끝은 통과)나 `코드`(그 끝도 실패)와 근거를 쓴다.
