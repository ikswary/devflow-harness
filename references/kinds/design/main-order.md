# 설계 task: 메인 순서

읽는 때: 메인이 설계 task(`design`)를 다룰 때.

- 설계가 「전체 검증에 더할 것」을 냈으면 승인 뒤 전체 검증 task의 머리 파일 「범위」에 "더한 범위(출처 {task id})"로 옮긴다.
- 실행 시작 때 기록한 커밋 안 된 변경 파일이 어느 task의 「건드릴 파일」과 겹치면 그 설계 task의 승인 화면 「정해 주실 것」에 올린다.
- 공통 설계 없이 설계가 둘 이상 나란히 돌면 어느 설계도 실행 전체 몫을 쓰지 않고, 메인이 설계 task 행이 모두 생긴 뒤 **실행 전체 설계 task**(`kind: design`, 제목 `설계 — 실행 전체`, 흐름 없음, `depends_on`에 모든 설계 task, 판정 기준은 「자체 검증」 가운데 실행 전체 몫에 해당하는 것)를 만들어 이 몫만 맡긴다. [RP-10]
