# 설계 task: 화면 정본이 있는 묶음

읽는 때: 그 묶음에 화면 정본 `ui\{묶음}.md`가 있는 설계 task를 쓰거나 판정할 때(그 화면 정본과 UI 규약은 `references/kinds/design.md` 「먼저 읽을 것」).

하는 일에 더하는 것:
- 「화면」 절은 화면 정본을 가리키고 구성 요소로 옮기기만 하며 요소·문구를 새로 정하지 않는다.
- 화면 정본과 다르게 배치·조작 흐름·문구를 정한 것도 알릴 결정의 질문 2(`references/kinds/design.md` 「하는 일」 3)에 걸린다(요소를 더하거나 빼면 알리는 것이 아니라 묻는다).

자체 검증에 더하는 것:
8. 화면 정본이 있으면 그 화면·요소·상태마다 담당 구성 요소와 닫는 구현 task가 있고, 설계가 화면 정본에 없는 요소·문구를 새로 정하지 않았다(판정자가 화면 정본의 화면·요소 id 목록을 설계와 대조).
