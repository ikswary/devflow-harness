# 화면 설계 task: UI 규약 task의 자체 검증 (읽기 판정)

읽는 때: 제목이 `화면 설계 — UI 규약`인 task(`ui\rules.md`를 씀)를 쓰거나 판정할 때.

원 산출물은 `ui\rules.md`뿐이고 자식은 없다(`references/kinds/ui-design.md` 「자체 검증」 1~8 대신 아래를 적용한다).
1. `references/practices/ui-spec/rules.md` 「UI 규약」의 항목마다(토큰 넷·글자 크기 셋·간격 둘 / 모양 다섯 / 문구 톤·오류 문구 꼴·버튼 글자 / 터치 크기·대비) 값이 있거나 기존 규약의 위치(파일:줄)를 가리킨다. 빈 항목이 있으면 실패.
2. 기존 규약의 위치가 실재하고 내용이 인용한 대로다(판정자가 연다). `recon.md` 「UI 규약」이 "없음"이면 모든 항목이 이번 실행의 값이다.
3. 틀 폭(폰·데스크톱)이 정해져 있다.
4. 구성 요소·클래스·저장 형식을 정한 문장이 없다.
