# 화면 설계 task: 과도기 예외

읽는 때: 부모가 요구사항 상세인 화면 설계 task를 쓰거나 판정할 때.

**과도기 예외**: 부모가 요구사항 상세인 화면 설계 task(옛 규칙으로 상세가 쓴 행)는 그 묶음의 설계 행 하나를 쓴다(`kind: design`, `flow`는 묶음 이름, 범위에 "화면 정본 `ui\{묶음}.md`(채택 줄 포함)를 따른다", 정본의 절에 `ui\{묶음}.md` 전부와 `spec\{묶음}.md`, 건드릴 파일에 `design/{흐름}.md`. 공통이 아닌 묶음의 설계는 공통 설계에 의존, id를 모르면 범위에 적고 메인이 채운다).
