# 화면 설계 task: 메인 순서

읽는 때: 메인이 화면 설계 task(`ui-design`)를 다룰 때.

- 화면 설계 task면 승인을 묻기 직전에 와이어프레임을 사용자 브라우저로 연다(`start "" "{와이어프레임 절대 경로}"`. 메인의 로컬 명령이고 저장소 밖으로 나가지 않는다. 거부되면 경로만 보인다). 사용자는 결과 파일을 보지 못하므로 시안 항목에는 글자 배치도가 있어야 한다(`references/kinds/ui-design.md` 4). 시안을 고른 답은 메인이 정본 「시안」 표 아래에 `채택: 안 (가) — {시각}` 한 줄을 더해 반영한다(3절 답 처리 표의 "준비된 선택지를 고름" 행).
