# 배포 계획 task: 배포만으로 시작한 경우

읽는 때: 배포만으로 시작한 실행(설계의 배포 계획 줄과 마무리가 없음)의 배포 계획 task를 쓰거나 판정할 때.

설계의 배포 계획 줄과 마무리가 없다. 작성자가 요청 원문과 `origin` 실행 마무리의 배포 메모에서 환경·확인할 것·배포 뒤 적을 문서를 찾아 이 task의 결과에 그 줄을 직접 쓴다. 메인은 작성자를 띄우기 전에 개발 기준 브랜치의 끝에서 배포 폴더를 만든다(흐름 이름 `deploy-{n}`, `formats.md` 1절). 원래 폴더는 쓰지 않는다.
- 1.2.0부터 시작한 이 실행은 최종 CI가 없다. 화면이 그 사실을 보이고, 배포를 닫는 것은 사람의 답 `승인|위험 수용 최종 CI 없음|{원문}`뿐이다(메인이 `decisions.md`에 표지를 쓴다).
- 배포 메모나 요청을 읽어 보니 배포 전에 코드·배포 도구를 고쳐야 하면 계획을 쓰지 않는다. 고칠 것과 근거를 「정해 주실 것」에 적고 반환의 `이상 신호`에 "코드 변경 필요"를 쓴다. 메인은 이 task를 `보류`로 닫고 질문 → 설계로 다시 시작한다.
