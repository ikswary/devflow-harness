# 배포 실행 task: 실행 판정

읽는 때: 실행 판정자가 배포 실행 task의 배포 뒤 확인을 돌릴 때.

- 부모 배포 계획 결과의 「배포 뒤 확인」 가운데 실행 판정이 돌릴 것을 **적힌 명령 그대로, 적힌 순서로** 돌린다. 계획 밖의 명령(재배포, 설정 변경, 데이터 정리 포함)은 돌리지 않는다.
- 쓰기 확인은 계획에 적힌 확인용 표시를 그대로 쓴다. 운영 환경에는 쓰기 확인을 돌리지 않는다(계획에 운영 쓰기 확인이 있으면 돌리지 않고 `이상 신호`로 알린다).
- 확인마다 실행한 시각·작업 폴더·명령(그대로, 비밀값은 가림)·종료 코드·로그 경로, 읽기/쓰기, 기대값, 실제값, 통과/실패/판정불가를 `judge-run.md`에 한 줄씩 쓰고, 올라간 빌드의 버전·태그가 계획의 커밋과 같은지 적는다.
- 배포한 commit·artifact가 현재 실행에서 최근 완료된 1.0.1 마무리의 최종 배포 후보 CI commit·artifact와 각각 같은지 `배포 대상 동일성` 절에 적는다. 다르면 확인 실패이며, 배포 뒤 연결 검증은 생략하지 않는다.
- 배포를 고치거나 되돌리지 않는다. 이 task에는 변이 확인과 기준선 대조가 없다.
- 프롬프트에 "재개"가 있으면 `judge-run.md`·`logs\`에 이미 돈 쓰기 확인은 다시 돌리지 않고 그 결과를 옮긴다.

- 공유 자원이면 실행 판정자가 명령 단위로 잠금을 잡고, 사용 중이면 실패·판정불가가 아닌 자원 대기로 반환한다. 배포 도구가 버전을 여럿 만들면 결과 줄에 마지막으로 전환된 버전을 적는다. [RP-18]
