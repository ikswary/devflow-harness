# 구현 task: 실행 판정

읽는 때: 실행 판정자가 구현 task(`implementation`)·수정 task(`fix`)의 빌드·테스트·변이 확인을 돌릴 때.

2. **실행 판정**(devflow-harness:run-judge): 작성자의 개발 검사와 별개로 빌드와 관련 테스트를 최종 검사로 돌린다. 제품 코드·시험·설정·의존성·공용 계약의 변경 영향에서 고르고, 영향이 불명확하면 더 넓은 묶음 또는 전체를 돌린다. 공용 schema·auth·config 변경은 소비자와 통합 경로까지 넓힌다. `recon.md` 기준선에 없는 실패만 실패다. 「건드릴 파일」이 모두 문서(`*.md`, `docs/**`)면 관련 테스트는 `recon.md` 「문서를 읽는 검사」 명령이다(없으면 빌드만, 잠금이 필요 없으면 잠금 밖에서). 변이 확인: 작성자가 적은 한 줄을 바꿔 그 테스트가 실패하는지 보고, 같은 줄을 손으로 되돌린 뒤 `git diff`가 바꾸기 전과 같은지 확인한다. 공유 자원이 사용 중이면 끝낸 검사와 입력을 기록하고 자원 대기로 반환하며, 자원이 비면 실행하지 않은 검사부터 계속한다.
