# 탐침 task (`probe`)

로컬에서 확인할 수 없는 가정(요금제 한도, 플랫폼 동작, 실제 연결)을 실험 명령으로 참·거짓을 가린다. 사람이 넘긴 「하실 일」과 설계가 쓴 자료 받기도 이 그릇에 담는다(`origin: 하실 일 넘김 {id}`). 단계 kind다: `실행승인 → 실행 → 기록 → 결과승인 → 끝`. 작성자는 계획 단계와 기록 단계에 한 번씩 뜬다. 명령은 메인이 `exec.py`로 돌리고, 실행 판정은 없다(기록은 읽기 판정이 실행 출력과 대조한다).

## 먼저 읽을 것
부모 결과 「확인 안 된 것」의 그 `[탐침]` 가정과 부모 정본의 해당 절, `recon.md`(명령·잠금).
- 인프라 작성자(`infra-writer`): `${CLAUDE_PLUGIN_ROOT}/references/practices/release-practice.md`
- 구현 작성자(`code-writer`): `${CLAUDE_PLUGIN_ROOT}/references/practices/build-and-test.md`

## 하는 일
### 남는 것
「범위」의 `남는 것:` 줄이 기준을 가른다. 메인이 넘긴 일에 `자원`을 적고, 설계가 쓴 행은 그 행의 값을 따른다. 비면 `없음`이고, 넘긴 일은 적히지 않아도 `자원`이다. 넘긴 일 안에서 새로 정할 것이 생기면 정하지 않고 「정해 주실 것」에 `[성질: 밖]`으로 올린다.

| `남는 것:` | 쓰임 | 계획 기준 | 기록 |
|---|---|---|---|
| `없음` | 가정 확인 | 임시 자원의 생성과 삭제까지, 작업 트리·저장소를 바꾸지 않음 | 가정마다 `참`/`거짓`/`판정불가` |
| `자원` | 넘긴 일, 공유 dev에 남는 쓰기 | 만든 자원마다 되돌리는 명령과 비용, 자원 목록을 인프라 정본에 적을 줄(`앞 정본 줄` 꼴) | 만든 것과 확인한 상태 |
| `파일` | 자료 받기 | 저장소 밖 경로(`_workspace\…`)에만 쓴다, 비밀값·식별자 검색, 받은 파일을 읽을 task | 받은 것, 크기, 검사 결과 |

### 단계
**계획**(첫 작성자):
1. 가정마다 번호, 문장, 참과 거짓을 가르는 관찰, 실험 명령(임시 자원의 생성과 삭제까지), 비용, 되돌리기를 본문에 쓴다.
2. 명령은 「정해 주실 것」의 `cmd` 울타리에 자리 표시 없이 한 줄에 하나씩 적는다. 사용자가 돌릴 줄은 `[사용자 실행]`. 명령은 관찰을 출력으로 내고 종료 코드 0으로 끝나며, 작업 트리와 저장소를 바꾸지 않는다.

**기록**(인스턴스 `{줄임}-{id}-rec`):
3. `exec.md`와 `logs\`를 읽고 결과 파일에 `## 탐침 기록` 절을 쓴다. 표 `| 가정 | 판정 | 관찰 | 근거 로그 |`, 판정은 `참`/`거짓`/`판정불가`.
4. 「승인 화면」을 기록 단계의 칸으로 다시 쓴다. 거짓인 가정마다 「정해 주실 것」에 "그 가정에 기댄 정본 {파일}의 {절}을 고친다 / 받아들인다"를 올린다.

## 승인 화면
- 계획: 정해 주실 것 = 실험 명령, 비용·되돌리기 / 알릴 것 = 명령이 도는 폴더.
- 기록: 정해 주실 것 = 거짓 가정의 처리 / 알릴 것 = 가정별 결과 한 줄 / 확인 안 된 것 = 판정불가 가정.
- `남는 것: 없음`이고 모든 가정이 참이고 「정해 주실 것」이 0이면 알림으로 지나간다. `자원`·`파일`은 결과 승인을 늘 묻는다(결과가 저장소 밖에 남는다).

## 자체 검증 (읽기 판정)
계획 단계:
1. 가정마다 관찰이 참·거짓을 가른다(판정자가 "이 출력이면 참, 이 출력이면 거짓"을 가정마다 써 본다).
2. 명령이 `cmd` 울타리에 자리 표시 없이 있고, `남는 것: 없음`이면 임시 자원을 지우는 줄이 있다. `자원`·`파일`이면 위 표의 계획 기준을 채웠다.
3. 작업 트리·저장소를 바꾸는 명령(`git` 쓰기, `파일`이 아닌데 파일 쓰기 리다이렉트)과 비밀값이 없다.

기록 단계:
4. 가정마다 판정이 `exec.md`의 종료 코드와 `logs\` 출력과 맞다(판정자가 하나씩 연다).
5. 거짓 가정마다 「정해 주실 것」 항목이 있다.
6. 계정 식별자·호스트명이 기록에 없다.
