# UI 규약 (`ui\rules.md`, UI 규약 task가 씀)

읽는 때: UI 규약 task(`ui\rules.md`를 씀)를 쓰거나 판정할 때. 화면 설계서·와이어프레임 작성법 `references/practices/ui-spec.md`에서 나눈 절이다.

기존 규약이 있으면(recon 「UI 규약」: 디자인 토큰 파일, 컴포넌트 폴더, 스타일 가이드·문구 규칙 문서) 항목마다 그 위치(파일:줄)를 가리킨다. 덧대기식 스타일 파일 더미는 규약이 아니다(recon이 "없음(스타일 파일 n개)"로 적는다). 없으면 이번 실행의 값을 정한다. 항목은 모두 채운다:
- 토큰: 바탕·글자·강조·오류 색 넷, 글자 크기 셋(제목·본문·보조), 간격 둘(칸 안·칸 사이).
- 모양: 버튼(기본·강조·위험), 입력 칸과 오류 표시 자리, 목록 줄, 카드, 대화상자(제목·본문·버튼 둘).
- 문구: 톤과 높임(예: "~합니다"), 오류 문구의 꼴(무엇이 왜 안 되고 무엇을 하면 되는지), 버튼 글자는 동사.
- 최소: 터치 영역 44px 이상, 글자·바탕 대비 4.5:1 이상(플랫폼 지침이 있으면 그것).
- 틀 폭: 폰(예: 360px), 데스크톱(예: 1024px). 와이어프레임이 쓴다.
