## 한 장 올리기

`visual.py --sheet`가 만든 `sheet.html`을 모바일에서도 보도록 비공개 Artifact로 올린다. 값은 「이번 실행의 값」 `한 장 올리기`(`허용` / `없음`)의 마지막 행이고, 행이 없는 옛 실행은 `없음`으로 읽는다.

**시작에 한 번 묻는다**(새 실행, 첫 task 전). 다시 묻지 않는다.

> 이 실행에서 승인을 물을 때마다 그 화면의 한 장을 claude.ai 비공개 페이지로 올릴까요? 코드 변경, 설계·요구사항 문서, dev 응답, 화면 캡처가 올라갑니다. 글에서는 일부 비밀값 꼴과 전화번호·메일 꼴만 가리고, 이름·주소·업무 내용은 그대로입니다. 화면 캡처는 전혀 가리지 않습니다. (허용 / 없음)

답을 받은 턴에 `run.md` 표에 `| 한 장 올리기 | 허용 |`(또는 `없음`) 행을 쓰고, `decisions.md`에 원문과 함께 한 줄을 쓴다. 뜻이 분명하지 않으면 `없음`이다.

**도중에 거두면** `| 한 장 올리기 | 없음 |` 행을 더하고 `decisions.md`에 원문을 적는다. 그 뒤로 올리지 않고 화면도 자료를 접지 않는다. 이미 올린 페이지는 남으므로 그렇게 알리고, 지우라고 하면 지운다.

**승인을 묻기 전**(`허용`일 때). 알림으로 지나가는 task와 코드 확인 카드는 올리지 않는다. 이 차례대로 한다.
1. `--sheet` 출력에 `올릴 파일:` 줄이 있으면 그 경로를 Artifact 도구로 올린다. 같은 경로면 같은 링크로 갱신된다.
2. `visual.py {실행 폴더} {id} --sheet-sent "{링크}"`로 남긴다. 표지는 지금 한 장의 내용에 묶여 `tasks\{id}\sheet-sent.md`에 쓰인다.
3. `screen.py … --save`로 화면을 남기고, 받은 링크를 질문 본문에 넣는다. 화면은 이 표지가 있을 때만 자료를 접으므로 표지를 먼저 남긴다.

**묻는 꼴**(`허용`일 때). `--save`의 `묻기:` 줄대로, 승인을 `AskUserQuestion` 대신 일반 메시지로 낸다. 모바일에서는 그 도구의 미리보기와 앞선 본문이 보이지 않아, 사람이 코드와 자료를 못 본 채 답하게 되기 때문이다. 터미널에서도 같다. `승인 요청 꼴`과 자료 뒤에 도구로 낼 문항을 항목 번호와 선택지 글자로 그대로 적고(`3 (가)/(나)`, `승인 / 고칠 것이 있음 / 나눠서 다시 / 보류`) 턴을 끝낸다. 답은 `screen.py … --answer`로 푼다. 꼴에 맞지 않거나 `승인`만 왔는데 선택지가 있는 항목을 고르지 않았으면 종료 3이니 되묻는다. 선택지 없는 항목(명령 목록 같은 것)은 `승인`이 닫는다. 앞서 고른 답은 `--record`의 지점이나 결정 칸에 항목 번호와 글자를 적는다(`2|(가)|{원문}`). 값이 `없음`이거나 `--once`로 한 번 올린 때는 지금처럼 도구로 묻는다.

**실패해도 승인을 막지 않는다.** `한 장 없음`이거나, `올리지 못함` 줄이 있거나, 도구가 거부하면 `visual.py {실행 폴더} {id} --sheet-failed "{사유}"`로 남기고 `file://` 줄과 사유를 보인 뒤 그대로 묻는다. 자료는 접히지 않는다. 고쳐서 다시 시도하지 않는다.

**`없음`이면 올리지 않는다.** 사람이 그 자리에서 요청하면 위 질문의 문장을 먼저 보이고, 받은 원문을 `decisions.md`에 적은 뒤 `visual.py {실행 폴더} {id} --sheet --once`로 그 한 번만 같은 차례로 올린다. 값은 바꾸지 않는다.

**손으로 쓴 페이지는 어떤 경우에도 만들지 않는다.** 올리는 것은 `sheet.html` 그대로이고, 내용을 고치거나 다른 파일을 쓰지 않는다. 한 장에 빠진 것이 있으면 작성자에게 「리뷰 자료」를 고치게 한다.

측정: `collect.py --measure`의 `한 장 올리기` 줄이 값과 두 표지의 횟수를 센다.
