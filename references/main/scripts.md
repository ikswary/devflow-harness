## 스크립트
`python ${CLAUDE_PLUGIN_ROOT}/scripts/{이름}` 으로 돌린다. 명령행과 옵션은 스크립트마다 `--help`에 있다.
| 스크립트 | 쓰는 때 |
|---|---|
| `board.py` | 다음에 할 일을 고를 때마다. 머리 파일을 통째로 여러 개 읽지 않고 이것을 본다. `--ready`는 kind별 시작 조건까지 보고, 합칠 수 있는 흐름·다시 검증하는 task가 없는 수정·보류에 막힌 task, 기록 점검 걸림과 하네스 판본 줄을 붙인다. 작업 공간의 남은 백로그는 `--backlog` |
| `task_set.py` | 머리 파일을 만들거나 고칠 때마다(상태와 `stage`, 승인 기록, 본문 절에 한 줄, 재시도 보관, 판정 기준 정정) |
| `exec.py` | 밖으로 나가는 명령을 돌릴 때(`--step`·`--verify`, 7절). 얼림(`--freeze`)은 `task_set.py`가 승인 기록과 함께 부른다 |
| `spawn_children.py` | 부모가 승인된 뒤 자식의 머리 파일을 만들 때, 승인된 고친 판을 쓰는 전용 task의 바뀐 행을 옮길 때(`--replace`). 손으로 옮겨 적지 않는다. 고른 안·백로그로 남길 안·수정 세대 상한도 옵션으로 넘긴다 |
| `screen.py` | 승인 화면의 재료와 칸별 항목 수, 알림 조건 충족 여부 |
| `machine_check.py` | 등록표 `needs_touch_files`인 task의 기계 조건(종료 코드 3이면 읽기 판정) |
| `eol_setup.py` | 새 실행의 프로젝트 설정 단계(0절 3의 2 「줄 끝 고정」). 점검만, 또는 `.gitattributes` 쓰기와 줄 끝 정리를 스테이징까지(커밋은 메인) |
| `board.py --ascii` / `board_ascii.py --watch {초}` | 진행 상황 그림. 사용자가 보자고 할 때만 메인이 찍는다(`--watch`는 사용자가 따로 띄워 두는 것) |
