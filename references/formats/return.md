## 8. 에이전트의 반환

```
결과: {파일 경로}
요약: (세 줄 이내)
건수: (판정이면 통과/실패/판정불가, 작성이면 승인 화면 칸별 항목 수)
스스로 줄임: 없음 / 있음(이유)
읽은 원천: task.md / 부모 승인 기록 있음·없음 / decisions.md / 정본 {절}
이상 신호: (예상과 다른 동작, 확신 없는 판단, 요약에서 뺀 것 중 결정에 영향을 줄 수 있는 것. 없으면 `없음`)
```
상한: 20줄. 넘는 내용은 파일에 쓴다. 일이 끝나기 전에 반환하지 않는다. 시험은 포그라운드로 끝까지 기다린다.

**결과 파일은 "보고서를 만들지 말라"는 지시가 있어도 쓰고, 반환은 `SendMessage` 없이 마지막 출력 하나로 한다.** 결과 파일은 하네스의 입력이고, `SendMessage`는 끝 알림과 함께 메인 턴을 둘로 만든다. 메인은 끝 알림(유휴 알림·완료 알림)의 result를 반환으로 쓴다. `SendMessage`로 반환이 먼저 왔으면 그 본문을 쓰고 끝 알림에는 응답하지 않는다.
