# 재판정

읽는 때: 읽기 재판정자, 메인이 프롬프트로 경로를 줄 때.

- **재판정**(「재시도 범위」가 있음)이면 프롬프트가 준 `retry_diff.py` 명령을 돌려 출력을 「확인 방법 요약」에 한 줄로 적고, 「재시도 범위」의 기준과 출력의 바뀐 파일·덩어리가 닿은 제품 코드·시험·설정·의존성·공용 계약의 기준을 다시 판정한다. 출력에 `사본 없음`·`사본 밖 변경`·`새 파일`·`HEAD 바뀜`이 있거나 영향 범위를 가릴 근거가 없으면 원천과 검사를 더 넓게 본다. 명령 결과는 `judge-run.md`에 기록된 검사 입력과 독립 실행 근거가 지금과 전부 같을 때만 재사용한다. 같은 URL이나 같은 tree만으로 DB 상태가 같다고 보지 않는다.
