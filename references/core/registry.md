# 등록표 (생성: python3 scripts/kinds.py --md-write. 손으로 고치지 않는다)

등록표 `scripts/kinds.py`를 절마다 한 파일로 낸 것의 목차다. 절 번호는 아래 표의 차례이고, "registry.md n절"은 이 표의 n번 파일이다.

| 절 | 파일 |
| --- | --- |
| 1. kind 17 | `references/registry/kinds.md` |
| 2. 간선 | `references/registry/edges.md` |
| 3. 에이전트 8 | `references/registry/agents.md` |
| 4. 값 집합 | `references/registry/values.md` |
| 5. 머리 파일 키와 본문 절 | `references/registry/task-keys.md` |
| 6. run.md 키와 시작값 | `references/registry/run-keys.md` |
| 7. 판본 칸 | `references/registry/version.md` |
| 8. 파생 집합 | `references/registry/derived.md` |
| 9. 독자별 formats 파일 | `references/registry/readers.md` |
