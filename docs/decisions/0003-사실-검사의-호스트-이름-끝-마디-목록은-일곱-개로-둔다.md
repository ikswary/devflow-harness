# 사실 검사의 호스트 이름 끝 마디 목록은 일곱 개로 두고 마디 꼴 규칙만 더한다

- 날짜: 2026-11-17
- 정한 사람: 사용자(원문 "1가")
- 상태: 유효

## 결정
`judge_facts.TLDS`(호스트 이름 끝 마디)는 `com`·`net`·`org`·`kr`·`io`·`jp`·`cloud` 일곱 개 그대로 두고, 이름으로 줍지 않는 꼴은 `judge_facts.NOT_IDENTIFIER_FORMS` 표 하나(파일 이름, 호스트 이름, 마디 꼴, 번호 꼴)로 모은다.

## 버린 길
- `app`·`info`·`me`·`dev`·`us`·`co` 등을 끝 마디에 더하는 길: `logger.info`, `req.app` 같은 코드 이름까지 사실 파일에서 빠진다.
- 끝 마디 목록만 계속 늘리는 길: 같은 갈래의 결함이 다시 나온다(`docs/plugin-practices.md` 「피드백 일반화」).

## 근거
저장소와 실행 폴더 md 5,921개에서 바꾸기 전후 줍는 결과가 같았다.
