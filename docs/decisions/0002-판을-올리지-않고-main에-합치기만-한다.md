# 시험 효율화 변경은 판을 올리지 않고 main에 합치기만 한다

- 날짜: 2026-11-17
- 정한 사람: 사용자(원문 "4. 나")
- 상태: 유효

## 결정
병렬 시험, 시험 고르기, 관문 훅 `.catch`, 항목 번호·이름 줍기 정리, 규칙과 검사를 묶는 시험, 목적 시험 이관은 판본을 올리지 않는다. `.claude-plugin/plugin.json`과 marketplace의 판본은 1.3.0 그대로이고, `CHANGELOG.md`에는 `1.3.0(이어서)` 꼴 행으로 적는다. 목적 시험은 이번에 돌리지 않는다. origin push와 플러그인 설치는 하지 않았고 사용자가 따로 승인한다.

## 버린 길
- 1.3.1로 올리고 목적 시험을 돌리는 길: 목적 시험 한 번의 비용이 크다.

## 근거
동작이 바뀌는 변경(관문 훅 실패 줄, 항목 번호 읽기)이 있으나 판을 낼 때 하는 `claude plugin validate --strict .`·`plugin details`·목적 시험을 이번에 돌리지 않기로 했다. 목적 시험을 다시 돌릴 준비물(`tests/purpose/`)은 이번에 저장소에 들어갔다.

## 되돌리려면
다음 판(1.3.1 이상)을 낼 때 `docs/plugin-practices.md` 5절의 판을 낼 때 점검을 모두 돌리고 `docs/operations/unverified.md`의 목적 시험 전 준비를 마친다.
