# 같은 흐름 코드 task의 자동 의존은 겹치는 앞 행과 계약 행으로 좁힌다

- 날짜: 2026-11-18
- 정한 사람: 사용자(원문 "이 실행의 범위에 넣어"(방향), "1. 가 / 2. 모두"(T021), 1.4.0 넘김 "ㅇㅋ 그대로"(T021))
- 상태: 유효(부모 task가 1.3.1부터 시작한 실행에만 걸린다. 이 실행의 부모는 1.3.0이라 걸리지 않았다)

## 결정
- 자식을 만들 때 같은 흐름의 코드 행은 이 자식 목록의 앞 코드 행 가운데 「건드릴 파일」이 겹치는 행 모두와 「시그니처와 결정 번호」에 `[계약]`이 든 행 모두에만 자동으로 의존한다(`spawn_children.py`).
- `recon.md`의 `- 덧붙이기 파일:` 줄에 든 파일(이 저장소는 `CHANGELOG.md`)은 겹침으로 세지 않는다.
- 앞 행의 결과(이름, 파일)를 쓰는 행은 설계가 `depends_on`에 직접 적는다. 이 규칙은 문서 행에만 있던 문장을 코드 행으로 넓힌 것이다.
- 겹치는 앞 행은 가장 가까운 하나가 아니라 모두에 의존한다.
- 칸 배정의 파일 겹침과 규약 행 판별은 그대로 둔다.

## 버린 길
- (나) 칸 배정까지 좁히는 길(덧붙이기 파일 겹침을 세지 않고 넣기 충돌을 union 병합으로 풀기, 규약 행을 `[계약]`·마이그레이션 행으로 좁히기). 칸 2 이상 실행이 생겨 효과를 잴 수 있을 때 1.4.0에서 한다.
- 가장 가까운 겹침 행 하나만 의존하는 길: 겹침이 사슬로 이어지지 않아 앞 행이 승인을 기다리는 동안 같은 파일을 동시에 고칠 수 있다.

## 근거
칸이 1일 때 앞 형제가 커밋한 뒤 승인을 기다리는 동안에도 겹치지 않는 뒤 형제가 기다렸다. 이번 실행의 T012·T013·T014가 그 예였다. 덧붙이기 파일을 세면 이 저장소의 모든 코드 행이 `CHANGELOG.md`로 겹쳐 바뀌는 것이 없다.
